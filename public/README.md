# Public Assets

## School Logo

**IMPORTANT**: Please save your school logo image as `logo.png` in this directory.

The logo should be:
- File name: `logo.png`
- Location: `g:\educat\teacher-assessment-nextjs\public\logo.png`
- Recommended size: 256x256 px or higher (square format works best)
- Format: PNG with transparent background preferred

The logo will appear:
1. At the top of the main assessment page
2. At the top of the admin page
3. As the browser favicon/icon

Once you save the logo.png file here, refresh your browser to see it displayed.
